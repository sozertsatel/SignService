# История версий SignService

## v1.1.0 — 02.10.2026

- **Проверка ЭЦП без КриптоПро**: пункт «Инструменты → Проверить ЭЦП…»,
  CMS/CAdES с ГОСТ-2001, ГОСТ-2012 256/512, RSA и ECDSA; отчёт по каждому
  подписанту с экспортом в TXT и отменой проверки.
- Раздельные результаты для документа, значения подписи, привязки сертификата,
  доверия, отзыва и TSA. Цепочки сертификатов проверяются без криптопровайдера;
  вложенный корень автоматически не считается доверенным. Поддерживаются
  подписанные CRL/OCSP и сетевые запросы по выбору; отсутствие подтверждений
  отображается явно. TSA проверяется вместе с привязкой к подписи и запросу.
- Исправлены проверки объединения и МЧД: совпадение хеша больше не пропускает
  повреждённое значение подписи; исключённый подписант не оставляет старый
  вложенный документ, выбранный режим откреплённой подписи сохраняется.
- МЧД проверяется по текущим XML/SIG и копируется из проверенного снимка;
  конфликт имён файлов и противоречивые ИНН/СНИЛС останавливают операцию.
  Файлы подписи сохраняются через временный файл и атомарную замену.
- Ограничена вложенность ASN.1 и исправлен контроль переполнения длины.
  Тесты запускаются для pull request; сборка Windows зависит от их успеха.

- **Переработан интерфейс**: лог операций всегда виден (статусная строка
  убрана — всё пишется в лог); настройки штампа времени (CAdES-T, адрес TSA)
  вынесены в окно «Настройки…»; у файлов появилось контекстное меню (ПКМ):
  подписанты и проверка ЭЦП, приложение подписей, штамп, извлечение,
  сборка контейнера, открытие папки.
- **Просмотр подписантов и проверка ЭЦП**: окно с отчётом по каждому
  подписанту — сертификат, срок, время подписания, штамп времени,
  соответствие документу (для ГОСТ — Стрибогом на любой платформе)
  и криптопроверка подписи.
- **Диалог параметров штампа** перед операцией: страницы (первая/последняя/
  все/указанные «1,3-5»), дата, логотип, режим подписи копии; на каждой
  выбранной странице — ОТДЕЛЬНАЯ плашка на каждого подписанта
  (колонками из правого нижнего угла).
- **Штамп на PDF безопасен при соподписании**: по умолчанию подписывается
  ОРИГИНАЛ документа, а копия «имя (со штампом).pdf» создаётся отдельно
  без подписи — после подписания и со всеми подписантами итоговой подписи
  (по блоку данных на каждого). Прежний режим «подписывать копию со
  штампом» остался отдельной галочкой с предупреждением.
- **Доверенность МЧД** (кнопка «Добавить доверенность…», как в Контуре):
  загрузка XML (EMCHD_1) и подписи руководителя, криптографическая проверка,
  проверка срока действия и соответствия представителя
  сертификату по ИНН/СНИЛС; при подписании файлы МЧД копируются рядом
  с документом, номер МЧД добавляется в штамп на PDF.

## v1.0.0 — 21.08.2026

Первый выпуск. Возможности:

- **Подписание документов ЭЦП** (CMS/PKCS#7, усиленный формат CAdES-BES):
  drag & drop файлов и папок, кнопка «Обзор…», пакетное подписание
  со статусом по каждому файлу; откреплённая (.sig рядом) и прикреплённая
  (документ внутри) подпись.
- **ГОСТ через КриптоПро**: на Windows подпись создаётся нативным CryptoAPI
  (CryptSignMessage), OID хеша подбирается по типу ключа
  (ГОСТ Р 34.10-2012/2001), в подпись вкладывается вся цепочка сертификатов.
- **Атрибуты CAdES-BES**: время подписания и signing-certificate-v2
  (для ГОСТ-2012 certHash считается Стрибогом — собственная реализация,
  проверенная на векторах RFC 6986).
- **Штамп времени (CAdES-T)** по выбору: метка доверенного времени от TSA
  (RFC 3161), адрес службы настраивается.
- **Соподписание**: объединение своей подписи с существующей .sig и/или
  приложенными подписями других лиц; подписи под другой версией документа
  исключаются автоматически с указанием подписанта.
- **Инструменты без подписания**: объединение нескольких .sig в один;
  извлечение из криптоконтейнера (документ, откреплённая подпись, разбор
  по подписантам); сборка криптоконтейнера из документа и подписей;
  штамп на PDF без подписи.
- **Визуальный штамп на PDF**: плашка «Документ подписан электронной
  подписью» с данными сертификата, датой (по желанию) и логотипом
  организации; подписывается штампованная копия.
- **Сертификат без токена**: сохранение сертификата с закрытым ключом
  на компьютер (PFX с паролем — только для программы) или установка
  в хранилище Windows (для всех программ), с предупреждениями и удалением
  (PFX затирается).
- **Прочее**: запоминание выбранного сертификата и настроек, окно лога,
  автообновление через GitHub Releases, поддержка base64/PEM и BER
  (в т.ч. неопределённые длины) во входных подписях.
